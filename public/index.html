Point 1 · Charte Graphique

Harmonie Chromatique

Avant : Couleurs disparates (cyan flashy, rose fuchsia, bleu ciel), fond gris terne, aucun fil conducteur.
Après : Thème unifié bleu marine #1E3A8A, bleu primaire #2563EB, cartes blanches sur fond subtil #EEF2F9.
Point 2 · Médias & Identité

Photographies Professionnelles

Avant : Aucun visuel métier ni identité locale gabonaise. Logo basique.
Après : Bandeaux thématiques avec photos haute définition du Gabon (parc de Libreville, remise de clés, route côtière).
Point 3 · Ergonomie & Grille

Standardisation Access

Avant : Contrôles désalignés, espacements irréguliers, tables étriquées.
Après : Grille normalisée de 0,63 cm, tailles homogènes, contrôles à coins arrondis et typographie Segoe UI 11 pt.
Point 4 · Logique Métier

Requête des Locations en Cours

Avant : Seul critère DateFin >= Date() : affichait par erreur des réservations commençant dans plusieurs mois.
Après : Critère corrigé DateDebut <= Date() AND DateFin >= Date() (8 véhicules réels en location au 28/09/2026).
Point 5 · Intégrité Données

Correction Réservation n° 11

Avant : Date de début (13/02/2027) postérieure à la date de fin (06/12/2026), causant une durée négative (-69 j).
Après : Règle de validation SQL [DateFin] >= [DateDebut] et outil de correction instantané.
Point 6 · Indicateurs Métiers

Nouveau KPI Carburants

Avant : Espace vide sous les 5 meilleurs clients.
Après : Carte « Flotte par carburant » avec parts précises : Essence (51,7 %), Diesel (38,3 %), Hybride (10,0 %).

Guide Technique Microsoft Access & Cotes Exactes (cm)

Toutes les dimensions et positions sont prêtes à être saisies directement dans la feuille de propriétés d'Access (onglet Format : Gauche, Haut, Largeur, Hauteur). Aucun code VBA requis.

Réglages Généraux à Appliquer dans Access

  1. Contrôles à thème Windows : Dans Fichier › Options › Base de données active, cochez « Utiliser les contrôles à thème Windows sur les formulaires ».
  2. Nettoyage des bordures et diviseurs : Sur chaque formulaire : Sélecteur d'enregistrement = Non, Boutons de déplacement = Non, Diviseurs d'enregistrements = Non, Barre de défilement = Aucune.
  3. Taille standard des sous-formulaires : Section Détail : Couleur fond = #EEF2F9, taille 35,67 × 19,26 cm, Style bordure = Aucun.
  4. Importation des photos : Mode affichage = Découpage, Type image = Partagé (stockage unique dans le fichier .accdb).
