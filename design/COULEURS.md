# Palette RENTAL GABON CAR

Palette de l'interface Access et des maquettes. Les codes hexadécimaux sont prêts à reprendre dans les propriétés de couleur des contrôles.

| Usage | Couleur | Code |
|---|---|---|
| Menu latéral / fond bleu marine | Bleu marine | `#1E3A8A` |
| Boutons principaux, icônes et trait d'accent | Bleu principal | `#2563EB` |
| Survol du menu et des boutons principaux | Bleu foncé | `#1D4ED8` |
| Indicateur « Chiffre d'affaires » | Bleu profond | `#1E40AF` |
| Indicateur « Voitures » | Bleu vif | `#2563EB` |
| Indicateur « Clients » | Bleu clair | `#3B82F6` |
| Fond du contenu | Bleu-gris très clair | `#EEF2F9` |
| Bandeau des titres de cartes | Bleu-gris pâle | `#F2F6FD` |
| Carte, champs et texte sur bouton principal | Blanc | `#FFFFFF` |
| Bordures de cartes et séparateurs | Bleu-gris | `#D3DDEE` |
| Bordures des champs | Gris bleuté | `#C9D0DA` |
| Texte principal | Anthracite | `#111827` |
| Libellés | Gris foncé | `#4B5563` |
| Texte secondaire | Gris | `#6B7280` |
| Bouton de suppression / alerte | Rouge | `#DC2626` |
| Fond au survol de suppression | Rouge très pâle | `#FEF2F2` |
| Bordure de suppression | Rouge doux | `#E8A5A5` |

| Carte | Fond | Pastille d'icône |
|---|---|---|
| Chiffre d'affaires | `#1E40AF` | `#3F5BBE` |

| Clients | `#3B82F6` | `#5C97F8` |

## Règles d'utilisation

- Garder le bleu marine pour la navigation et les voiles photo ; le bleu vif sert aux actions et éléments sélectionnés.
- Utiliser le rouge uniquement pour une action destructive (Supprimer) ou une erreur.
- Conserver les fonds de carte blancs et les fonds de page bleu-gris pâle pour préserver le contraste.
- Dans Access, saisir les codes dans les propriétés `Couleur fond`, `Couleur bordure` et `Couleur texte`.
