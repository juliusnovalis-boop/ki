Couleurs : bleu royal `#002366`, or `#C9A24B` (dégradé `#F3DC94` → `#A3802F`), argent `#C4CAD3`, blanc.
Polices du nom : Cinzel (1, 3, 4) ou Michroma (2, 5, 6) ; inutile de les installer, le nom est déjà dans l'image.

Dans Access : contrôle **Image**, `Mode affichage image` **Zoom**, fond transparent. Les logos sont prévus pour un fond foncé.
Une fois le logo choisi, il remplacera `logo-connexion.png` et `logo-menu.png` dans les maquettes.
