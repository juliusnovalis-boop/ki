# Couleurs · ONYX CAR

Projet **ONYX CAR** · design **Éditorial** · couleurs **noir et blanc**.

## Comment saisir une couleur dans Access

1. Sélectionner le contrôle, ouvrir la **Feuille de propriétés** (F4), onglet **Format**.
2. Dans *Couleur fond*, *Couleur texte* ou *Couleur bordure*, taper directement le code **`#RRVVBB`** (exemple : `#111111`) puis Entrée.
3. Ou cliquer sur **…** › **Autres couleurs** › onglet *Personnalisées* et saisir Rouge, Vert, Bleu (colonne RVB).

## Photos

Les photos de `assets/photos/` sont déjà recadrées et teintées (voile `#0D0D0D`, noir et blanc) : il suffit de les insérer avec un contrôle **Image**, ou en propriété **Image** du formulaire.

## Polices

Segoe UI pour les contrôles ; **Georgia** pour les grands titres, les chiffres des indicateurs et le montant.
